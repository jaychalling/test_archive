0. 운영 철학 (절대 원칙)
핵심 정의

Test-archive.com은 “콘텐츠 비즈니스”가 아니다.
트래픽을 자동으로 생산·순환시키는 ‘엔터테인먼트 UX 상품’이다.

따라서:

❌ 신뢰 쌓기

❌ 전문가 포지셔닝

❌ 깊은 정보 제공

전부 의도적으로 하지 않는다.

3. 테스트 선정 기준 (Gate)

새 테스트는 아래 조건을 모두 통과해야 추가 가능

Gate A — 수요

Google에 동일 테스트 이름 검색량 존재

Reddit / TikTok 언급 존재

1회성 트렌드 ❌

Gate B — 반복성

질문이 시간에 따라 바뀌지 않음

업데이트 필요 없음

Gate C — 결과 공유성

“점수” 또는 “유형”이 명확

친구에게 보여줄 수 있음

4. 사이트 구조 규칙
4.1 고정 URL 구조
/                 → Archive Hub
/tests/           → 테스트 목록
/test/{slug}/     → 테스트 페이지
/test/{slug}/result/ → 결과 페이지


slug = 테스트 이름 그대로

변형 URL 생성 ❌
